# mzLib 1.0.586 — variant decoys, reproducible match-between-runs, and SDRF

**Source:** `1.0.585..1.0.586` (15 PRs)
**Contributors:** @acesnik, @trishorts

Three items change answers you already have. **If you search variant databases, use FlashLFQ match-between-runs, or read MGF files, read the first four items before upgrading.** Nothing here changes a target framework, removes a public API, or drops a file from the package.

## Highlights

- **A variant database was not one decoy per target (#1154)** — A protein carrying an insertion immediately after the initiator methionine produced four target entries and a *single* decoy. Reversing that insertion yielded a variation beginning one residue past the end of the sequence with an empty original sequence, which reads as invalid — and one invalid variation caused every variation on that decoy to be discarded. Target-decoy counts were therefore unbalanced in exactly the way FDR estimation assumes they are not, so **q-values from earlier searches over variant-containing databases were computed against a short decoy set.** Two fixes: a variation that cannot be expressed as one contiguous replacement on the reversed sequence (a start loss, which changes both ends at once) now costs only itself instead of taking every other variation with it; and previously applied variations are no longer discarded as "overwritten" when a deletion's collapsed span happens to share a position with a later edit. `Protein` gains an optional trailing `nonVariantProtein` parameter so a decoy mirrored from a variant target points at the consensus rather than at itself — additive, and existing call sites compile unchanged. Databases without sequence variants are unaffected.

- **Match-between-runs was not reproducible (#1155)** — The PEP model's training rows were appended per thread under a lock, so their order depended on which chunk finished first. FastTree runs single-threaded from a fixed seed, but row order changes its binning and split choices, so the model — and every PEP it predicted — differed between runs on identical input. Those PEPs order the target-decoy walk that assigns `MbrQValue`, and the peptide roll-up keeps an MBR peak only while its q-value is under the threshold, **so a peptide whose only evidence was a transferred peak could report its real intensity in one run and zero in the next.** Rows are now filled into one slot per donor and flattened in donor order: same rows, same model input, fixed order. If you have been averaging repeated FlashLFQ runs to smooth this out, you can stop.

- **`MergeResultsWith` silently zeroed half the merged data (#1151)** — The quantification allow-list was not unioned across the merge, so peptides arriving from the merged-in results were blanked by the next `CalculatePeptideResults` and then not repopulated. The allow-list is now unioned, and it is also copied rather than aliased at construction, so merging no longer mutates the set the caller passed in. `MergeResultsWith` now documents what wins on a key collision.

## Readers

- **MGF: MS level round-trips, and there is now an MGF writer (#1165)** — Every scan read from an MGF was previously reported as MS2 regardless of content. A block now takes its level from `MSLEVEL` when the writer supplied one, and otherwise reads as MS2 if it carries a precursor and MS1 if it does not. **Files predating `MSLEVEL` all carry `PEPMASS`, so they read exactly as before**; a file containing genuine MS1 blocks stops claiming they are MS2. The new writer makes MGF a round-trippable format rather than read-only.

- **MGF: multi-digit and unsigned charge states (#1164)** — The `CHARGE` parser stripped the last character unconditionally, on the assumption that it was a sign. An unsigned `CHARGE=12` was therefore read as charge 1. The sign is now stripped only when present. Polarity is still derived from the sign, and negative charge states parse.

- **`GetClosestOneBasedSpectrumNumber` is a binary search (#1163)** — O(n) to O(log n), which matters because `GetMsScansInTimeRange` starts every call here. Three behavioral edges are now specified rather than incidental: an empty file returns 0; a tie returns the last scan sharing the closest retention time; and for MGF and MsAlign — whose scan numbers can have gaps, and whose overridden scan accessor the old walk could throw on — it returns a real scan number where the old code returned a position. The ascending-retention-time assumption is not new (the old walk stopped at the first local minimum, so it never looked past one either), but it is now written down, along with the fact that MGF stores `NaN` for an absent `RTINSECONDS` and nothing detects it. See #1175.

- **Bruker and timsTOF paths are built with `Path.Combine` (#1159)** — `FilePath + @"\analysis.baf"` is a Windows-only construction; on Linux and macOS a backslash is an ordinary filename character. Two bare `throw new FileNotFoundException()` calls now name the path they could not find, and **a missing `.d` directory raises `DirectoryNotFoundException` rather than `FileNotFoundException`** — adjust any `catch` that relied on the old type.

## SDRF-Proteomics

- **Read, write, validate and pool SDRF-Proteomics files (#1138)** — A full document model: typed cells, headers and rows, a validator, and a drift lint. `.sdrf.tsv` joins `SupportedFileType` as the **32nd** recognised format, mapped to `SdrfDocument`. Consumers that assert on the number of supported formats will need that count moved.

- **Build an SDRF-Proteomics file from a search (#1174)** — `SdrfBuilder` assembles a document from search inputs, with a coverage report naming which columns could be filled and which could not.

## Remote services

- **PRIDE: an understated `total_records` no longer truncates a file manifest (#1173)** — The file pager trusted the server's record count. Where that count was understated, the fetch stopped early and returned a partial manifest with nothing to indicate it was partial. It now fetches one further page whenever the fetch would otherwise end on a page that could be full, costing one extra request per fetch of that shape and nothing for a fetch ending on a visibly short page. An overstated count was already handled. The one remaining gap is documented on the method: an understated total on a single page requested above the server's cap. The pager is now shared rather than duplicated per endpoint.

- **Find PRIDE projects by keyword (#1187)** — `search/projects`, returning typed results with yearly download counts.

- **A stalled UniProt download can no longer hang a job (#1189)** — `ProteinDbRetriever` gains two minutes for the service to start responding and a two-minute inactivity deadline on the transfer itself. Previously a stall had no deadline at all: one live test spent 12m43s before the runner cancelled the job, which reports as a red check on every open PR. This PR also fixes the exclusion that was supposed to keep live external-service tests out of the required CI run — `--filter "Category!=ExternalService"` does not exclude a test carrying more than one category, because VSTest evaluates the not-equals against each projected trait individually. The exclusion is now an NUnit `Where` clause in `Test/required.runsettings`, which evaluates against the whole category set.

## Packaging and project

- **Four dependencies were missing from `mzLib.nuspec` (#1179)** — `Nett`, `Newtonsoft.Json` 13.0.4, `TopDownProteomics` 0.0.299 and `ZstdSharp.Port` 0.8.7 are now declared in both target groups. They were always required at runtime; consumers were resolving them by accident or carrying their own reference. **A consumer pinning a lower version of any of the four will now see `NU1605`** — MetaMorpheus was aligned ahead of this release in MetaMorpheus #2740 and #2741. Nothing was removed from the nuspec, so no paired installer change is required.

- **Third-party notices now record the redistributed native libraries and the Chronologer model (#1161)** — Documentation only.

- **Contribution licence stated as LGPL-3.0-or-later (#1167)** — `CONTRIBUTING.md` had drifted from `LICENSE`. Documentation only; the licence itself is unchanged.
