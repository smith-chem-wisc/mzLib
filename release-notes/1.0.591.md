# mzLib 1.0.591 — digestion, XML validity, and search reliability
**Source:** `1.0.590..master` (`19a29301b9e3ada261fe22576fcdc385d3cfa9f7..45386c825857f21b00abb84f0d6635a34649555f`, 9 PRs)
**Contributors:** @acesnik, @Alexander-Sol, @nbollis, @trishorts

This release renames the shipped `RNase PhyM` definition. **Any consumer that looks an RNase up by that name will throw** — see the first item below before upgrading.

## Highlights

- **The shipped `RNase PhyM` definition is renamed (#1301)** — `rnases.tsv` now carries `RNase PhyM (>= 7M urea)` and `RNase PhyM (< 7M urea)` in place of the single `RNase PhyM`, because the two denaturing conditions cleave differently. `RnaseDictionary.Dictionary["RNase PhyM"]` therefore throws `KeyNotFoundException`; select the entry matching your condition. The same change adds `RNase I` and `non-specific`. MetaMorpheus needs a one-line change before it can take this release — `MetaMorpheus/Test/ParameterTest.cs:337` is its only use of the old name, and MM master's suite fails there today.
- **Semi-specific digestion now returns the peptides searches request (#1303, #1304)** — `SearchModeType.Semi` with `FragmentationTerminus.Both` previously returned only C-terminal seeds, causing searches to miss most semi-specific identifications. The digestion edge cases now return the complete peptide set with correct labels and missed-cleavage counts. A follow-up fixes the remaining case where a removed initiator methionine is itself a cleavage site; the reported `MPEPTIDEPEPTIDE` fixture previously missed 13 of 14 peptides. Seed requests with termini N or C remain unchanged.
- **mzML and mzIdentML output is schema-valid and version handling is safer (#1171, #1183)** — Generated XML IDs now obey NCName rules, missing source metadata receives safe fallback values, and the mzIdentML 1.1.0 namespace is corrected while preserving readability of files written with the old namespace. Version dispatch no longer uses repeated `NullReferenceException` handling, so genuine parse and indexing errors are reported accurately.

## Bug Fixes

- Correct semi-specific peptide generation for CNBr-like or other proteases that cleave after the initiator methionine. Regression tests compare the complete peptide set, labels, and missed-cleavage counts against a brute-force reference across the digestion settings matrix. [#1304](https://github.com/smith-chem-wisc/mzLib/pull/1304)
- Make mzML identifiers valid for schema consumers, including filenames beginning with digits or containing invalid XML-ID characters; preserve the original filename in the source-file metadata. [#1171](https://github.com/smith-chem-wisc/mzLib/pull/1171)
- Read and write mzIdentML 1.1.0 with the correct namespace, while remapping the legacy namespace for existing mzLib-produced files. [#1171](https://github.com/smith-chem-wisc/mzLib/pull/1171)
- Report retention-time error distributions using the observed donor/acceptor variation for match-between-runs scoring instead of a fixed standard deviation. The public `RtDiff` sign convention now matches the calibration calculation. [#1216](https://github.com/smith-chem-wisc/mzLib/pull/1216)
- Keep Koina model-stall tests from failing the suite when the external model is unresponsive, while retaining failures for malformed requests and local assertion errors. [#1295](https://github.com/smith-chem-wisc/mzLib/pull/1295)

## Enhancements

- Document the interaction between `SearchModeType` and `FragmentationTerminus`, including when `Protein.Digest` returns peptides versus seeds, and add coverage for every routing combination. [#1304](https://github.com/smith-chem-wisc/mzLib/pull/1304)
- Track multiple possible RNA digestion termini through `Rnase`, `NucleolyticOligo`, and `OligoWithSetMods`, exposing the termini needed to interpret digestion products. Expand tests for non-specific and Cusativin digestion. [#1301](https://github.com/smith-chem-wisc/mzLib/pull/1301)
- Align the nuspec dependency declarations with the packaged projects: update stale ML and serializer versions, pin `SharpLearning.Optimization`, and remove unused dependencies. [#1278](https://github.com/smith-chem-wisc/mzLib/pull/1278)

## New Features

- Add standalone `StcE` as an embedded protease, in addition to the existing `StcE-trypsin` combined digest. This enables StcE-only digestion for workflows that need longer, site-dense O-glycopeptides. [#1249](https://github.com/smith-chem-wisc/mzLib/pull/1249)

## Refactoring

- Replace exception-driven mzIdentML accessor dispatch with direct null checks and add regression coverage protecting embedded shipped protease names. [#1183](https://github.com/smith-chem-wisc/mzLib/pull/1183) [#1304](https://github.com/smith-chem-wisc/mzLib/pull/1304)

**Compatibility notes:** Semi-specific search results change because previously missing peptides are now returned. `RetentionTimeCalibDataPoint.RtDiff` changes sign from acceptor-minus-donor to donor-minus-acceptor; no in-repository external consumer was found. The RNA termini properties and digestion signatures are public API changes from #1301, which also renames the shipped `RNase PhyM` entry as described above.

**Validation reported by the PRs:** The semi-specific changes report 6,153 and 6,257 full-suite passes respectively; the XML changes report 217 schema-focused tests passed; the Koina change reports 6,029 passed and 32 skipped in the required suite.
