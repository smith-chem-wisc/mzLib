# mzLib 1.0.596 — TMT quantifies a peptide shared by indistinguishable proteins, SDRF designs keep their own numbers, and new DIA and statistics building blocks
**Source:** `1.0.595..1.0.596` (`d10017ce..f5684a77`, 22 PRs)
**Contributors:** @pcruzparri, @trishorts

**MetaMorpheus master fails three tests against this release.** mzLib's `integration` job has been red since #1426
merged (2026-10-16). Two MetaMorpheus pull requests fix the three tests. Both are drafts on trishorts/MetaMorpheus and
wait only for this package; see **Downstream: the integration job**.

Two changes give existing callers different answers:
- **TMT quantification now gives a value to a protein group whose proteins share every peptide (#1463).** Before, a
  match to one sequence in several proteins was dropped as ambiguous.
- **An SDRF label-free design keeps the replicate and fraction numbers the SDRF writes (#1426)**, gaps included. Before,
  it renumbered them or refused the gaps.

Several smaller answers change too: msp spectra with no retention time, parser errors on malformed modification
strings, and modification lookup by name.

One change can stop a Koina subclass compiling (#1390). Two public methods change in a way that needs a rebuild (#1468,
#1390). No file was added to or removed from the package. No target framework changed.

## Breaking changes

- **Koina model subclasses: a protected member was removed, and another changed signature (#1390).**
  - The protected static `CTerminalModStripper` is gone. It shipped in 1.0.595.
  - The protected `TryCleanSequence` gains a fourth parameter, `ISequenceParser? sourceParser`.
  - Only a class deriving from a Koina model is affected; callers are not. MetaMorpheus and ProteaseGuru override
    neither member.
- **Recompile against this release (#1468).** `PtmPairEngine.CoVarying`'s `excludeCeiling` is now `bool?`, where it was
  `bool`; null means the old default. It also gains the optional `includeBounds` and `runCovariate`. Source compiles
  unchanged. A binary built against 1.0.595 that calls it throws `MissingMethodException` until it is rebuilt.

## Changed answers

- **A sequence found in several proteins is quantified as one peptide (#1463, fixes #1280)** — in `QuantificationEngine`
  (isobaric/TMT):
  - A match is ambiguous only when its candidates have different full sequences. Before, one sequence in several
    proteins was excluded.
  - There is one peptide row per full sequence. `GetPsmToPeptideMap` now returns one key per full sequence.
  - A peptide is unique when exactly one protein group lists its full sequence. That is judged across all groups,
    including groups that are not quantified, through the new every-group constructor and
    `GetUniquePeptideToProteinMap` overload.
  - **Measured on PXD014145 (TMT11) through MetaMorpheus:**
    - multi-protein groups with a value went from 0 of 59 to 59 of 59;
    - 2,239 single-protein groups' values rose and none fell;
    - peptide rows went from 83,062 to 79,065;
    - identifications were byte-identical.
  - FlashLFQ's label-free path is not touched.
- **SDRF label-free designs keep the SDRF's numbers (#1426)** — in `SdrfLabelFreeDesign` (`--sdrfDesign`):
  - Biological replicates are kept as written: control 1–3 and treated 4–6 stay 4–6, where they became 1–3.
  - A missing or `not available` replicate is numbered after the condition's highest number, instead of refused.
  - A gap in fractions or technical replicates is kept and noted. Only a duplicate is still refused.
  - New notes in `Notes` and `Report()` say what was numbered and what is not 1..N.
  - `IsValid` can now be true for a design that current MetaMorpheus refuses (see **Downstream**).
- **msp spectra with no retention time read as null, under any culture (#1472)**
  - A record with no `RT`/`iRT` now reads `RetentionTime == null`, not 0. That includes third-party files. Code that
    assumed 0 needs `?? 0`.
  - The writer no longer writes an empty `RT=`. Before, a ProteaseGuru library with no retention times made
    `SpectralLibrary` throw.
  - Numbers and keys are read and written in the invariant culture. Under de-DE, `RT=30,5` used to read back as 305.
- **Malformed modification strings are refused (#1457)** — `MzLibSequenceParser` and `MassShiftSequenceParser` now
  reject an empty modification (`PEP[]TIDE`), anything after a C-terminal modification, two leading groups, and two
  modifications on one residue. Before, they parsed silently as a different peptide (a dropped oxidation left it
  15.995 Da light, for example) or failed later with an unrelated error. They throw, return null or warn according to `SequenceConversionHandlingMode`.
  ProForma is unaffected.
- **Every same-name modification stays a lookup candidate (#1442)** — duplicates are now removed by reference, not by
  `Modification` equality, which ignores location. Terminal and side-chain entries with one name both stay. 18 terminal
  Unimod entries (`Methyl on X`, `Ethyl on X`, …) now serialize to ProForma as `[UNIMOD:34]` and similar, not typed
  names.
- **Koina validates every input the same way (#1390)**
  - A pre-resolved ProForma `[UNIMOD:N]` now faces the model's allow-list. Before, it bypassed the list.
  - The Prosit 2020 TMT models check the N-terminal label by UNIMOD id, not by text.
  - Each input record can carry its own `SequenceParser` (below).
- **Site occupancy reports more `NotDetected` rows (#1468)** — `SiteOccupancyCalculator.Calculate` emits one whenever a
  covering peptidoform was identified. Before, it needed one quantified above zero. `CoVarying` results with default
  arguments are unchanged.
- **A cancelled PRIDE download keeps its `.partial` (#1481)**
  - `PrideArchiveClient.DownloadFileAsync` leaves the `.partial` on disk when the caller cancels, so the next call
    resumes it. A caller that expects a clean folder after cancelling will now find `.partial` and `.partial.validator`
    files.
  - With `verifyMd5: true`, a `.partial` from a host that sends no `ETag` or `Last-Modified` (PRIDE's Globus HTTPS) is
    now resumed. The MD5 check catches a bad splice and downloads again from byte 0.
- **SDRF readers and drafters**
  - `SdrfIsobaricDesign` now reads a TMT10 SDRF that labels its last channel `TMT131`, as PRIDE spells it (#1467).
    PXD015833 reads all ten channels. TMT11 `TMT131` is still refused.
  - A replicate cell saying `pooled` is now kept by the drafter and the evidence extractor (#1466). Before, it was
    dropped with a note.
  - The drafter now reads a deposit's own Spectronaut, MSstats or MaxQuant design table (#1483). An MSstats
    `BioReplicate` such as `patient_A` is no longer misread as a replicate number. PRIDE drafts made without evidence are
    byte-identical.
- **`AnalysisDesign.ByStratum` numbers default contrasts once per analysis (#1476)** — `c2` is now the same comparison in
  every stratum. `NotRun` lists each default contrast a stratum cannot run. `Create` on one stratum is unchanged.
- **DIA-NN parquet detection on a locked file throws (#1478)** — a busy or unreadable `.parquet` now throws
  `IOException` or `UnauthorizedAccessException` from detection. Before, it was reported as not supported.

## New

- **DIA building blocks:**
  - `MassSpectrometry.FragmentCoElution` scores fragment co-elution for a DIA precursor: `Score`, `FindApex`,
    `PeakBounds`, `TopIndices` (#1386).
  - `Chromatography.RetentionTimeCalibration.IrtCalibration` fits a run's retention times onto library iRT, LOWESS or
    linear, robust to outliers, never falling back to identity (#1387). It comes with the `MzLibUtil.Irt` and
    `MzLibUtil.RtMinutes` value types.
- **Statistics:**
  - `NestedMixedModel`: a per-feature nested linear mixed model with Satterthwaite df and empirical-Bayes moderation,
    checked against lme4, lmerTest and limma (#1471).
  - `LogitNormalMixedModel`: a random-intercept model whose samples are measured on a latent scale, or counted through
    it as binomial or beta-binomial k of n (#1469).
  - `StatisticalReportWriter` writes `StatisticalReport.md` with SVG diagnostics from the differential metadata and rows
    (#1475).
- **ptmQtl:**
  - `SiteTraitOptions.Scale` reports site-trait effects on the log2-odds scale, as an option (#1464). The default is
    unchanged, bit for bit.
  - `CoVarying` can include one-form cells as tied bounds and remove a per-run covariate (#1468).
- **Koina input records carry an optional `SequenceParser`** (#1390). Set it to `ProFormaSequenceParser.Instance`, for
  example, and ProForma goes straight in.
- **Ensembl Compara gene-tree alignments** (#1465): `ComparaGeneTreeAlignment.Load` and `MapResidue` map a residue
  across an alignment column.
- **`SdrfIsobaricLabels`** (#1467) is one channel/label rule for SDRF writers and readers. **`SdrfSample.Pooled`** (#1466)
  writes a pooled sample's replicate as `pooled`.
- **`DigestionMotif.NonPrimeSubsite` and `PrimeSubsite`** (#1485) name a motif residue by Schechter-Berger subsite. No
  digestion answer changes.

## Fixes

- **A refused `.parquet` is closed (#1478).** DIA-NN detection or loading used to leave the file locked. Parquet reads
  now also run off the UI thread, which avoids a deadlock in a WPF host.
- **The SDRF drafter can draft from a MassIVE record (#1482).** Its provenance now names MassIVE, not PRIDE. The API is
  internal.
