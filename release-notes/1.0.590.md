# mzLib 1.0.590 — what the package carries

**Source:** `1.0.589..master` (11 PRs)
**Contributors:** @acesnik, @nbollis, @pcruzparri, @trishorts

This release expands mzLib’s RNA and modification-format support, improves MGF and indexed-mzML interoperability, and fixes several correctness problems in quantification and occupancy workflows.

## Highlights

- **MGF interoperability:** Preserved MS1 peaks and precursor metadata so calibrated MGF round trips match mzML search results.
- **RNA workflows:** Added tRNA database support, a Pytheas search-match reader, inosine/Ψ representations, and RNase 4.
- **Modification formats:** Added Modomics modification parsing.
- **Indexed mzML:** Corrected checksums for files containing a UTF-8 byte-order mark.
- **Quantification:** Counted spectral results once per file rather than once per isobaric channel.
- **Equality correctness:** Fixed `Extremum` equality and hashing to prevent stack overflows and inconsistent dictionary behavior.
- **Peptide occupancy:** Removed unsafe PSM-object lookup keys that could crash on duplicate or unresolved matches.
- **TSV output:** Moved biopolymer-group rendering into a schema and writer so output columns remain consistent.

## Bug Fixes

- Corrected indexed-mzML checksums so files written with a UTF-8 byte-order mark can be verified by external consumers in [#1246](https://github.com/smith-chem-wisc/mzLib/pull/1246).
- Preserved MS1 peaks and precursor metadata in MGF files so calibrated MGF round trips retain the same search results as mzML in [#1227](https://github.com/smith-chem-wisc/mzLib/pull/1227).
- Fixed `Extremum` equality and hashing to prevent stack overflows and make dictionary-based grouping behave consistently in [#1219](https://github.com/smith-chem-wisc/mzLib/pull/1219).
- Counted each spectral-counting result once per file instead of repeating it for every isobaric channel in [#1296](https://github.com/smith-chem-wisc/mzLib/pull/1296).

## Enhancements

- Added inosine and Ψ nucleotide representations so pseudouridine alternatives can be represented in RNA workflows in [#1276](https://github.com/smith-chem-wisc/mzLib/pull/1276).

## New Features

- Added Modomics modification parsing so Modomics data can be read by mzLib in [#950](https://github.com/smith-chem-wisc/mzLib/pull/950).
- Added a Pytheas RNA search-match reader so Pytheas results can enter mzLib workflows in [#1277](https://github.com/smith-chem-wisc/mzLib/pull/1277).
- Added tRNA database support for RNA-focused database workflows in [#1289](https://github.com/smith-chem-wisc/mzLib/pull/1289).
- Added RNase 4 as an available protease specificity in [#1297](https://github.com/smith-chem-wisc/mzLib/pull/1297).

## Refactoring

- Moved biopolymer-group TSV rendering into a schema and writer so headers and rows remain consistent across datasets and sample paths in [#1285](https://github.com/smith-chem-wisc/mzLib/pull/1285).
- Removed PSM objects as peptide-occupancy lookup keys so duplicate or unresolved matches no longer crash occupancy calculation in [#1284](https://github.com/smith-chem-wisc/mzLib/pull/1284).
